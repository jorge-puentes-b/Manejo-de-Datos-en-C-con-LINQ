#Manejo de Datos en C# con LINQ

Proyecto desarrollado como parte de mi proceso de aprendizaje en **C# y .NET**, enfocado en el uso de **LINQ (Language Integrated Query)** para consultar, filtrar, ordenar y transformar datos de manera eficiente utilizando colecciones y expresiones lambda.

Este proyecto me permitió fortalecer habilidades fundamentales para el desarrollo Backend con .NET mediante la aplicación de buenas prácticas de programación y Programación Orientada a Objetos.

---

## Objetivos

- Comprender el funcionamiento de LINQ en C#.
- Aplicar consultas sobre colecciones de datos.
- Practicar el uso de expresiones lambda.
- Mejorar la organización del código utilizando Programación Orientada a Objetos.
- Fortalecer las bases para el desarrollo de aplicaciones Backend con .NET.

---

## Tecnologías utilizadas

- C#
- .NET
- LINQ
- Programación Orientada a Objetos (POO)
- Visual Studio / Visual Studio Code

## Requisitos

Antes de ejecutar el proyecto asegúrate de tener instalado:

- .NET SDK 8.0 o superior
- Visual Studio 2022 o Visual Studio Code

Puedes verificar la versión instalada con:

```bash
dotnet --version
```

---

## Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/jorge-puentes-b/Manejo-de-Datos-en-C-con-LINQ.git
```

### 2. Ingresar al proyecto

```bash
cd Manejo-de-Datos-en-C-con-LINQ
```

### 3. Restaurar dependencias

```bash
dotnet restore
```

### 4. Ejecutar la aplicación

```bash
dotnet run
```

## Funcionalidades

El proyecto permite realizar diferentes operaciones utilizando LINQ, entre ellas:

- Consultar información de una colección.

- Ordenar datos de forma ascendente y descendente.
- Obtener estadísticas de una colección.
- Transformar datos mediante proyecciones.
